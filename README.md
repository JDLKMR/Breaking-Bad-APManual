# Breaking Bad Manual APWorld
This is an Archipelago Manual that involves watching Breaking Bad and checking off locations as you watch certain, important scenes. Likewise, to watch scenes, relevant in-universe items and characters are required. Seasons, episodes, and timestamps are included in location names so it's clear where to go.

The Manual functions in an open-world fashion rather than a linear one.

Note that this Manual, of course, contains spoilers for Breaking Bad.
